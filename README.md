# NORYVX UI SYSTEM

GitHub-ready organization of NORYVX UI Sets 01–60.

## Structure

- `sets/UI_SET_01` through `sets/UI_SET_60`: each UI set preserved as its own independent folder.
- `manifests/`: package inventory and set metadata.
- `docs/`: repository-level integration and QA notes.

## Important

These packages are UI/design assets and documentation. They are not, by themselves, the game's runtime UI implementation code.

Set 60 is the shared/global UI system intended to provide reusable visual conventions for the previous sets.
