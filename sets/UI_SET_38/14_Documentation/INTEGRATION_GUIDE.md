# Profile Integration

Player identity must come from authenticated player data.
Level/XP values must come from authoritative progression.
Achievement unlocks must be validated by the progression system.
Titles, badges and banners require ownership/equip validation.
Equipped cosmetics must persist across sessions.
Statistics should be read-only presentation of authoritative match history.
Private/online status should follow the player's presence/privacy settings.
Profile updates should be safe across reconnects.
