# Social Integration

Presence must use authoritative session/presence state.
Friend requests must be server-side and idempotent.
Party membership and leader permissions must be authoritative.
Invites require permission and expiration handling.
Chat channels require server-side authorization, rate limits and moderation controls.
Clan roles and membership must be authoritative.
Player search must respect privacy and visibility rules.
Block/mute actions should be persisted and immediately applied locally.
Reports should create a moderation case without exposing reporter identity to the reported player.
