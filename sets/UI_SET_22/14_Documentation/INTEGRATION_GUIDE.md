# Settings Integration

Settings must have stable keys and validated ranges.
Audio and graphics values should be applied only after valid changes.
Control mappings need conflict detection and reset-to-default support.
Accessibility settings should be applied consistently across gameplay and UI.
Language changes require localized string bundles and fallback handling.
Account linking/logout must be explicit and recoverable.
Privacy choices must be stored according to the actual account/privacy implementation.
Notification preferences must not override platform-level notification permissions.
