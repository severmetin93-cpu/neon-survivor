# Quest Integration

Quest definitions must be data-driven.
Quest progress must be authoritative.
Tracking/pinning can be local presentation state unless synced by design.
Completion validation must happen in the progression system.
Reward grants must be idempotent.
Daily/weekly resets should use authoritative server time.
Story unlocks must follow prerequisite rules.
Failed/expired/abandoned quests must transition according to explicit game rules.
Client UI must not directly grant XP, currency or items.
