# Season Pass Integration

Season IDs and season end times must come from authoritative configuration.
Tier XP must be calculated from validated progression events.
Free and premium reward ownership must be checked before display/claim.
Claims must be idempotent and recoverable after interrupted transactions.
Premium entitlement must come from the account/purchase system.
Expired seasons must preserve historical reward/account records while disabling new progression according to the actual product rules.
