# Loading / Onboarding / Tutorial Integration

Show splash only during initial app boot.
Bind loading progress to real asset/system initialization.
Persist onboarding completion so returning players are not forced through it.
Tutorial steps must be gated by actual gameplay events.
Do not advance a tutorial step merely because the screen was displayed.
Pause menu must respect the game's pause model.
How-to-play content should remain accessible from pause/settings.
Localize all instructional text through the game's localization system.
