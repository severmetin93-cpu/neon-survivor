# Character UI Integration

1. Load the character selection background on the landscape character screen.
2. Render character cards horizontally with horizontal scroll if needed.
3. Selecting a card opens the detail panel.
4. Populate stats from runtime character data rather than hard-coded UI text.
5. Bind ability icons to actual ability definitions and cooldown state.
6. Bind equipment slots to inventory/equipment data.
7. Keep touch targets >= 48dp; prefer larger primary controls.
8. Validate all five characters at mobile scale and on 16:9 Android devices.
