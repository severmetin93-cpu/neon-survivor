# Season Pass Integration

Season ID and season timing must come from authoritative configuration.
Tier XP and mission progress must be server-validated.
Premium ownership must come from entitlement state.
Reward claims must be idempotent and uniquely identified.
Tier skips, if supported, must follow the same authoritative progression path.
Expired/ended season states must prevent invalid claims.
Season countdowns should use authoritative server time.
Client UI must not grant items, currency or XP directly.
