# Settings Integration

Settings should have a clear source of truth and deterministic save behavior.
Graphics options must respect device capabilities.
Audio settings should apply without restarting where supported.
Control bindings must validate conflicts before save.
Language changes should use localized resources and preserve unsupported fallback behavior.
Accessibility options should be applied immediately where feasible.
Privacy settings must be authoritative and respected by social systems.
Notification preferences should be synchronized when account-backed.
Logout and account deletion require explicit confirmation.
Account deletion must follow the platform/account retention policy and should never be presented as a casual one-tap action.
